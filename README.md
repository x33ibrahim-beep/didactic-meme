# SokotoPay – Flutter Starter

This is the first UI prototype for SokotoPay: data, airtime, electricity, DStv/GOtv, JAMB, WAEC, NECO, wallet and transaction history.

## Run
1. Install Flutter.
2. Open this folder in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Run `flutter run`.
